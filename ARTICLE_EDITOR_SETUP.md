# Article formatting and credit line

The shared editor for Tin tức Hot and Kinh nghiệm tìm MBKD now uses self-hosted Quill 2.0.3. It is available both inside `/admin` and in each public page's admin-only editing panel. Select text and use the toolbar for font, size, bold, italic, underline, strike, text/background color, headings, alignment, lists, blockquotes, links, clear formatting, undo and redo. The toolbar remains visible while editing long content. Font options: default, Arial, Times New Roman, Georgia, Verdana, Tahoma and Courier New; size options range from 10px to 72px. No remote editor service or API key is used.

Each paragraph beginning `Biên soạn:` automatically receives `news-credit` presentation in the editor and public reader: italic, weight 300 and a muted color. This applies immediately to existing plain-text articles without changing the stored wording or their images. Formatting cannot silently turn the credit line bold through inherited `<strong>` styling.

`news_articles.rich_content` stores an optional version-1 Delta document, while `content` remains canonical plain text for excerpts, integrations and compatibility. The server validates every operation and attribute, allows only enumerated fonts/sizes and safe colors/links, rejects embeds and unsupported formats, and renders escaped text with trusted tags/styles. It does not accept arbitrary stored HTML. Documents are bounded by text length, operation count and serialized size. Malformed/mismatched stored documents fall back to escaped plain text on reads. Public feeds omit rich documents; admin detail reads include the validated document.

Formatting survives save/reopen and status-only changes. Legacy plain-text updates intentionally clear obsolete rich formatting when their text changes. Existing revision checks, private drafts/archived articles and admin authorization remain intact. Telegram keeps its prepared-plain-text workflow. Cover uploads remain separate from body formatting.

Apply the additive `database/migrations/20261105_article_rich_content.sql` before deployment, using the repository SQL + authenticated Supabase apply_migration workflow (local CLI unavailable). No existing article body, photo, signature wording, grant or RLS policy is changed. The private admin request limit for article saves is 4 MB to accommodate formatting plus existing image uploads.

The pinned Quill distribution and license are copied into `public/vendor/`; update these together with the npm version. Shared font/size configuration is `public/article-format.js`, loaded by the browser and imported by the server. Rendering needs only the article CSS, not the editor library. The existing 12 Vercel handlers are reused.

Validation: `npm run check`; `tests/article-rich-text.mjs` (server validation, safe rendering, canonical text, storage/reload, legacy/status behavior); `tests/news-ui.mjs` (real toolbar selection, font/size/color/emphasis/alignment, links, undo/redo, save/reopen/reload, mobile layout, guest/expired-session privacy and computed credit styling); existing news, Telegram labels, experience and customer webhook tests. Tests fake DB/Telegram and never rewrite production content.
